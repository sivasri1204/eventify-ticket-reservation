🎟️ Eventify

Multi-Tenant Event & Ticket Reservation System built with Node.js, Express, SQLite3, and Vanilla Web Technologies.

Roles Supported

  • 👤 Attendee: Browse, hold seats, mock pay, download passes
  • 📊 Organizer: Create events, monitor sales & gross revenue
  • ⚡ Admin: Platform oversight, user governance, audit events

Core Engineering

  • 🛡️ Security: Parameterized SQL & bcryptjs
  • ⏱️ Fair Hold: 10-minute reservation lock
  • ⚡ Atomic: SQLite transactions prevent overselling
